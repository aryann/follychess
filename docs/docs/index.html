Overview

A UCI-compatible chess engine written in C++23.

FollyChess implements the Universal Chess Interface (UCI), so you can use it with a chess GUI such as Arena, Cutechess, BanksiaGUI, or HIARCS. You can also run it directly in a terminal.

These pages cover:

  • Installation: how to build FollyChess from source.
  • Usage: how to run the engine and which commands it supports.
  • Internals: where to find the source code and talks about how the engine works.
